Ejercicio 10.07

Indique si cada enunciado es verdadero o falso. Si es falso, explique por qué

  1. Para hacer referencia a un elemento específico de un arreglo, especificamos el nombre del arreglo y el valor del elemento.
    Falso. Se especifica el nombre del arreglo y el índice (posición) del elemento, no su valor.
  2. La declaración de una variable reserva espacio para un arreglo.
    Falso. var a; sólo crea la variable. El espacio del arreglo se reserva al crearlo con new Array( ... ) o con una lista inicializadora [ ... ].
  3. Para reservar 100 ubicaciones para el arreglo entero p se escribe p[ 100 ];
    Falso. Eso sólo hace referencia al elemento 100. La declaración correcta es var p = new Array( 100 );
  4. Un programa que inicializa los elementos de un arreglo de 15 elementos en cero debe contener cuando menos una instrucción for.
    Falso. También puede hacerse con una lista inicializadora ([ 0, 0, ..., 0 ]), con while, con for...in o con 15 asignaciones.
  5. Un programa que calcula el total de los elementos de un arreglo bidimensional debe contener instrucciones for anidadas.
    Falso. Es lo más común, pero también se puede con for...in anidados (como en la sección 10.10), con while o escribiendo cada suma a mano.
