Ejercicio 10.04

Instrucciones con el arreglo tabla

  1. Declarar y crear el arreglo con tres filas y tres columnas: 
    var tabla = new Array( new Array( 3 ), new Array( 3 ), new Array( 3 ) );
  2. Almacenar el número total de elementos en totalElementos: 
    var totalElementos = tabla.length * tabla[ 0 ].length;
  3. Usar for...in para inicializar cada elemento con la suma de sus índices (variables x y y). Respuesta del libro: 
    for ( var x in tabla )
{
   for ( var y in table[ x ] )
   {
      tabla[ x ][ y ] = x + y;
   }
}

La respuesta del libro tiene 3 errores

  1. Error de escritura: dice table[ x ] en lugar de tabla[ x ].
  2. El ciclo interno no hace nada: new Array( 3 ) crea 3 posiciones vacías (sin elementos). Como dice el Tip 10.2, for...in omite los elementos que no existen, así que el ciclo interno nunca se ejecuta y la tabla queda en undefined. Para que funcione, los elementos deben existir primero, por ejemplo creando la tabla con una lista inicializadora: var tabla = [ [ 0, 0, 0 ], [ 0, 0, 0 ], [ 0, 0, 0 ] ];
  3. Concatena en vez de sumar: en for...in las variables x y y son cadenas ("0", "1", "2"), así que x + y une texto: "1" + "2" da "12", no 3. Hay que convertirlas con parseInt.

Respuesta corregida:

var tabla = [ [ 0, 0, 0 ], [ 0, 0, 0 ], [ 0, 0, 0 ] ];   // los elementos ya existen

for ( var x in tabla )
{
   for ( var y in tabla[ x ] )
   {
      tabla[ x ][ y ] = parseInt( x ) + parseInt( y );
   }
}

Comprobación de las tres versiones
