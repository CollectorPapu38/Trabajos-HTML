Ejercicio 10.05

Encuentre el o los errores en cada segmento y corríjalos

  1. var b = new Array( 10 );
var longitud = b.length;

for ( var i = 0; i <= longitud; ++i )
{
   b[ i ] = 1;
}
    Error: con <= el ciclo llega a b[10], que está fuera de los límites (los índices válidos son 0 a 9). Es un error lógico, no de sintaxis: JavaScript no marca error, simplemente hace crecer el arreglo a 11 elementos.
    Corrección: usar i < longitud. 
  2. var a = [ [ 1, 2 ], [ 3, 4 ] ];
a[ 1, 1 ] = 5;
    Error: el indexado de arreglos bidimensionales se escribe incorrectamente. En JavaScript a[ 1, 1 ] se evalúa con el operador coma y equivale a a[ 1 ], por lo que reemplaza toda la fila 1 por el número 5.
    Corrección: a[ 1 ][ 1 ] = 5;
