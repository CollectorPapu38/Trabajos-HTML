Ejercicio 10.09

Arreglo t de dos por tres

  1. Declarar y crear: var t = [ new Array( 3 ), new Array( 3 ) ];
  2. ¿Cuántas filas? 2
  3. ¿Cuántas columnas? 3
  4. ¿Cuántos elementos? 6
  5. Elementos de la fila 1: t[1][0], t[1][1], t[1][2]
  6. Elementos de la tercera columna (índice 2): t[0][2], t[1][2]
  7. Fila 1, columna 2 en cero: t[ 1 ][ 2 ] = 0;
  8. Serie de instrucciones (sin ciclo): 
    t[0][0] = 0; t[0][1] = 0; t[0][2] = 0;
t[1][0] = 0; t[1][1] = 0; t[1][2] = 0;
  9. Con for anidado: 
    for ( var fila = 0; fila < t.length; ++fila )
   for ( var col = 0; col < t[ fila ].length; ++col )
      t[ fila ][ col ] = 0;
  10. El valor más pequeño: 
    var menor = t[0][0];
for ( var fila = 0; fila < t.length; ++fila )
   for ( var col = 0; col < t[ fila ].length; ++col )
      if ( t[ fila ][ col ] < menor )
         menor = t[ fila ][ col ];
document.writeln( menor );
  11. Sin repetición, mostrar la primera fila: document.writeln( t[ 0 ].join( " " ) );
  12. Imprimir t en formato tabular con índices de columna arriba e índices de fila a la izquierda (ver la ejecución).
