Ejercicio 11.01

Complete las siguientes oraciones

  1. Como JavaScript usa objetos para realizar muchas tareas, se conoce por lo común como lenguaje de programación basado en objetos.
  2. Todos los objetos tienen atributos y exhiben comportamientos.
  3. Los métodos del objeto Math nos permiten realizar muchos cálculos matemáticos comunes.
  4. Al proceso de invocar (o llamar) al método de un objeto se le conoce como enviar un mensaje al objeto.
  5. Las literales de cadena se escriben como una secuencia de caracteres en comillas dobles o comillas sencillas.
  6. Los índices para los caracteres en una cadena empiezan en 0.
  7. Los métodos indexOf y lastIndexOf de String buscan la primera y última ocurrencias de una subcadena.
  8. Al proceso de dividir una cadena en tokens se le denomina tokenización.
  9. El procesamiento de fechas y horas puede realizarse con base en la zona horaria local de la computadora o en el Tiempo Universal Coordinado (UTC).
  10. El método parse de Date recibe una cadena con una fecha y devuelve los milisegundos desde el 1 de enero de 1970.
  11. Las aplicaciones Web pueden usar la propiedad localStorage del objeto window para guardar datos entre sesiones y pestañas.
  12. Para datos de una sola sesión, separados entre pestañas, se usa la propiedad sessionStorage.
  13. Un selector :first-child de CSS3 selecciona el primer hijo de un elemento.
  14. Un selector :nth-child con "odd" selecciona los hijos impares y con "even" los pares.
